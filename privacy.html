星子拼豆隐私政策

更新日期：2026年10月27日
生效日期：2026年10月27日

星子拼豆（以下简称“本应用”）由吴鑫庄（以下简称“我们”）开发和运营。我们尊重并保护您的个人信息。本政策说明您使用本应用时，信息如何被处理，以及您可以如何管理自己的数据。

本政策适用于星子拼豆 Android 应用（包括通过华为、小米等应用商店分发的版本），以及同名官网、浏览器 / PWA 和桌面版本。系统能力因平台而异，仅在您使用相应功能时适用。

核心说明：本应用不需要注册或登录。照片转换、颜色匹配、路线计算、项目与制作进度保存均在您的设备上完成。我们不通过本应用上传您的照片或项目，不接入广告、用户行为统计或追踪服务。访问官网和主动分享文件涉及的联网或信息传输，详见下文。

一、我们处理哪些信息及其用途

我们遵循明确目的、最小必要的原则，仅为您选择的功能处理相关信息。在本机处理不等于向开发者上传。本应用没有接收照片、项目或制作记录的业务服务器。

  • 您主动选择的图片及文件：包括导入的照片、拼豆图纸、色卡、色板文件及项目备份，以及文件名、文件类型等必要信息，用于解码、裁剪、生成拼豆图、提取颜色和恢复项目。图片中可能包含人像或其他个人信息；本应用不进行人脸识别、身份识别或人像信息提取，也不将图片用于模型训练。
  • 创作与制作数据：包括项目名称、原图、像素网格、色板、颜色用量、路线、完成标记、制作时长、导航历史和保存时间，用于编辑、保存、继续制作及导出备份，保存在本机。
  • 使用偏好：包括主题、界面与解释偏好、导航设置等，用于记住您的选择，保存在本机浏览器存储或应用数据区。我们不使用这些数据分析您的行为或建立用户画像。
  • 运行环境信息：官网或应用会在本机判断操作系统、浏览器、触控及网络可用状态，用于推荐安装包、适配展示和调整界面文案，不以此生成持久设备标识或上传用户画像。
  • 您主动发送的反馈：当您通过邮件联系我们时，我们会接收您的邮箱地址、邮件内容及您主动附加的材料，用于回复咨询、处理隐私请求或排查您报告的问题。请仅提供与问题有关的信息。

本应用不要求提供姓名、手机号、身份证、支付信息等注册资料，不主动读取通讯录、通话记录、短信、精确位置、麦克风录音、已安装应用列表、IMEI、IMSI、MAC 地址、Android ID、OAID 或广告标识符。我们不将个人信息用于定向广告或自动化商业决策。

三、联网、第三方组件与服务

本地功能：照片处理、颜色匹配、路线计算和数据存储不依赖云端图像接口。我们未集成广告、推送营销、行为分析、社交登录、支付或崩溃统计上报 SDK。

官网与更新：当前官网和政策网页托管于 GitHub Pages（服务提供方为 GitHub, Inc.）。应用自身不会请求静态版本清单，也不会在后台访问网络；只有您主动打开官网或隐私政策时，系统浏览器才会访问相应网页。浏览器版首次访问及离线资源更新仍需要正常加载网页资源。

与普通网页访问相同，网络连接会向托管或下载服务暴露 IP 地址，请求还可能包含访问时间、资源路径及浏览器或系统自动生成的请求头。托管方可能为提供服务和保障安全处理相关访问日志；这不同于本应用上传作品。其处理地点、保存期限和保护规则由服务提供方决定，相关说明见 GitHub 通用隐私声明。GitHub Pages 可能使用境外基础设施，因此访问官网、政策或更新源时产生的连接信息可能由境外设施处理；本机照片和项目不会因此上传。

四、信息共享、转让与公开披露

我们不出售、出租或用于交易您的个人信息，不向广告商、数据经纪商共享信息，不主动公开您的图片或作品。

您主动导出、复制或通过系统分享面板发送文件时，数据会交给您选择的接收方。备份可能包含原始图片、项目和制作进度，请确认接收方并按需启用备份加密。这些操作不代表开发者能够访问您的作品。

对于您主动通过邮件提供并由我们持有的信息，如确因法律法规、司法或行政机关依法提出的要求需要提供，我们将核验要求并仅在必要范围内处理。若未来发生涉及个人信息转移的运营变更，将依法告知接收方及联系方式，并要求接收方履行相应义务；改变处理目的或方式时，依法取得所需授权。

五、信息存储、期限与保护

  • 存储位置：作品、原图、色板及进度存放于您设备的本地数据库；偏好存放于浏览器本地存储或应用数据区。不同设备、浏览器及网站来源的数据分别保存，不自动云同步。当前 Android 版本关闭了系统应用数据自动备份配置；设备或您自行使用的备份工具仍可能有独立行为。
  • 保存期限：本地数据通常保留至您删除项目、清空数据或系统回收存储空间。已导出的文件由您管理；移动端分享产生的临时文件可能保留在应用缓存目录，可通过系统清理缓存删除。卸载或清除应用数据可能造成不可恢复的丢失。
  • 反馈邮件：您主动发送的信息会在邮箱服务提供方的邮件系统中保存。我们仅在回复、处理请求或争议所需的期限内保留相关信息；处理结束后，不再需要的信息将删除或匿名化，法律要求保留的除外。您可通过下述邮箱提出删除请求。邮箱服务自身的存储与备份规则由其提供方决定。
  • 保护措施：应用利用操作系统及浏览器存储隔离机制；官网使用 HTTPS。备份可选择在本机进行密码加密，密码不上传、不持久保存。未加密备份和本地项目数据不应视为已进行应用层加密，请保护设备、文件和密码。忘记加密密码时，我们无法为您找回。

我们会采取与处理场景相适应的保护措施。若发生涉及我们持有个人信息的安全事件，将依法采取补救措施，并履行适用的通知和报告义务。

六、您的权利与数据管理

您可以通过以下方式访问、更正、复制、删除信息或改变授权：

  1. 查看与修改：在“我的项目”、编辑和色板等页面查看、编辑您保存在本机的作品和相关信息。
  2. 导出与迁移：在应用内的“数据与隐私”页选择“导出全部数据”或“导出当前项目”，保存备份并在其他设备导入。您可以选择为备份设置密码。
  3. 删除项目：在“我的项目”中删除不需要的项目。共享色板、其他项目以及已导出的副本可能仍然保留。
  4. 清空本地数据：在应用内的“数据与隐私”页展开“清空这台设备上的本地数据”，输入“清空”并确认。此操作删除应用数据库中的项目、原图、色板、路线和进度，并重置相关偏好；不会删除已导出的文件或其他设备上的副本。如需删除所有应用缓存和剩余界面设置，可使用系统“清除应用数据”，或清除对应网站的全部存储。系统分享接收方持有的副本需向其另行删除。
  5. 撤回授权：可在系统设置或浏览器网站设置中管理已授予的权限。应用不会在后台联网检查版本或上报数据，仅在您主动打开官网或隐私政策时访问网站。撤回授权不影响此前基于有效授权已进行的处理。
  6. 账号注销：本应用没有注册和登录系统，不存在需要注销的应用账号；可通过上述方式删除本地数据并停止使用。
  7. 联系我们：对于反馈邮件等我们实际持有的信息，您可以申请查阅、复制、更正、删除、撤回同意或解释处理规则。我们可能进行与请求相适应的必要身份核验，不会为处理请求要求无关的个人信息。

由于我们无法访问您设备上的作品，不能远程代为恢复、修改或删除本地项目。我们会在收到您的联系后十五个工作日内回复或说明处理进展；如法律法规对特定请求另有规定，将按其执行。对处理结果有异议的，您可再次联系我们，或依法向有关个人信息保护部门投诉、通过司法途径维护权益。

七、未成年人保护

未成年人应在监护人的指导下阅读本政策并使用本应用。不满十四周岁的儿童应在监护人同意和指导下使用。请监护人帮助管理图片、导出文件、权限及外部分享，避免发送含有儿童身份、住址、学校等不必要信息的材料。

本应用不主动识别或收集儿童身份信息，不为儿童建立画像。如果监护人认为儿童在未经有效同意的情况下向我们发送了个人信息，请通过下述邮箱联系我们。经必要核实后，我们将依法处理删除等请求。

八、本政策的更新

我们可能因功能变化或法律要求更新本政策，并在本页面标明更新及生效日期。涉及处理目的、处理方式、信息种类或权利行使方式等重大变化时，将通过应用内提示或其他适当方式告知；依法需要另行取得同意的，将在相关处理开始前取得同意，不以本政策更新本身替代您的授权。
